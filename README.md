# Cartas de la Abuela

Prototipo de SINAPXIUS: un misterio familiar contado en cartas. Un toque por acción, sin Game Over, dificultad adaptativa y capítulos que se abren por constancia.

Jugar: https://benjaminperez164-del.github.io/cartas-abuela/

Modo de prueba: toca 5 veces la versión (abajo a la derecha) para simular el día siguiente.

Contenido: capítulo 1 (7 días) y capítulo 2 (5 días).
